# 一覧・TOB比較・試算のUI改善

2026-10-07のユーザー依頼に基づき、優先度が高かった4項目、スマホ表示、比較倍率を試算欄へ取り込む操作を1つのPRにまとめる。株探は便利用の外部リンクとして維持し、サイト内の操作経路には位置付けない。

## 変更した表示と操作

- TOB一覧に会社名・証券コードの検索、公表期間、成立状況、選択中の指標の倍率がある事例のみの絞り込みを追加。全角・半角をそろえて検索する。件数は価格の段階別と明記し、一覧と詳細を同じ条件で絞り込む。
- TOB詳細は買付価格・成立状況・取引倍率・第三者機関の評価レンジを先に表示。取引条件、算定根拠、価格履歴は折りたたみ、全文・日付順の履歴・出典・価格版ID・旧リンクを保持。業種別集計は開いて参照でき、会社名・期間・成立状況の検索条件が集計に適用されないことを明記する。
- 同業事例が1件の集計は「参考事例1件の倍率」と表示し、平均・中央値・最小・最大の重複をなくす。試算株価の強調を弱め、倍率±10%の計算例は任意に開く表示にする。予測幅として扱わない。
- 追跡一覧の未取得の株価・指標4列は初期非表示。「株価・指標を表示」で再表示でき、未取得の説明と「—」を保持する。CSSによる切替でJavaScriptが無効でも動く。
- スマホでは検索の段階選択を1行の横スクロールにし、状況検索を媒体・期間とともに折りたたむ。適用中の条件は件数と解除ボタンで確認できる。TOBでは業種と指標を並べ、タップ領域を44px以上にする。
- 銘柄の参考倍率に「この倍率で試算する」を追加。押したときだけ指標と丸める前の倍率を試算欄へ反映し、その参考欄と同じ会社予想／実績の一式を選択する。入力済み株価は保持し、試算欄へ移動して倍率入力にフォーカスする。反映元の条件を表示し、倍率・指標・財務基準を手動変更したら反映元表示を消す。欠損数値などで試算できない参考値は取り込めない。

## 検証とレビュー

全181件のNodeテストが成功。追加検証は1件の表示、全精度の倍率反映、入力株価保持、会社予想／実績の区別、欠損時の操作禁止、検索・期間エラー・価格版と旧リンクの到達を対象とした。既存の認証・個人メモ・お気に入り・RLSの回帰検証も成功。Astro検査はエラー0・警告0（既存のヒント3件）。サンプル33ページのビルドと静的成果物検査、EDINETのPython13テストが成功。

ローカルのサンプル表示を320px・390px・1280px幅で確認。指標列の表示切替、全角コード検索、試算ボタンによるEV/EBITDA11倍の反映と1,550円の計算、入力株価1,400円の保持、試算欄への移動を確認した。実端末とログイン済み本番での手動操作は今回の確認範囲外。

自己レビューで差分と操作を確認し、型の不一致、テストURLの不足、期間エラー時の案内、折りたたみ条件の適用件数、JavaScript無効時の案内を修正した。数値の出典・計算定義と公開範囲は変更しない。natural-japaneseの手動検査（uv未導入）とux-writingの10項目で、公開する文言と折りたたみ内の説明を点検した。
