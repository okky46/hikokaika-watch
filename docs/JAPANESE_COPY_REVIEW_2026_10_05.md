```powershell
npx skills add coji/natural-japanese --global --agent codex --yes
npx skills add plugin87/ux-ui-agent-skills --skill ux-writing --global --agent codex --yes
```

## 文章検査の判断

各ページを短い独立した文章としてnatural-japaneseのクイック手順で点検した。uvが未導入のため、Skillが指定する手動チェックリストで定型句、否定対比、文のリズム、段落の均質さ、語順、重複を確認し、見出しから本文への流れと差分を読み直した。機械リンターの実行済みとは扱わない。

ux-writingは公開前の10項目を確認した。日本語では「メモを保存」のように対象と動作を自然な順序で書く。タブ名・見出しは名詞のまま保持し、API名・JSONキー等は管理者が設定を識別するために必要な箇所へ残した。会社発表を分類する「会社発表ではない」や引用内の否定は事実の区別に必要なため保持した。ブラウザー標準の確認ダイアログや入力エラーの仕組みは変更していない。
