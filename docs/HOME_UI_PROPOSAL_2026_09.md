# トップページのUI改善案（2026-09-29・提案段階）

PR #19の詳細デザインを管理者が承認し、本番反映を依頼。同時にトップページの改善提案を依頼した。この文書は提案であり、トップページの追加実装・公開を承認済みとは扱わない。

## 画面確認で分かったこと

検索、媒体、期間、個人用条件、解除、件数が大きな検索カードに集まっている。390px幅では最初の画面がほぼ説明と検索で埋まり、銘柄を見るまでスクロールが必要。媒体チェックボックス、通常の青いリンク、ステータス表示が混在している。3列一覧・行クリック・確認日1か所・現在のフォントは維持する。

## 優先して実装したい案

1. **段階をタブへ**。「すべて／正式発表前／正式発表後／完了・終了」を件数付きで表示し、現在の「段階」ドロップダウンを置き換える。噂段階と観測報道等の細かな区別は常時表示の「今の状況」で選ぶ。「お気に入り」は段階と併用できる独立した切替にする。分類確認中の案件がある場合は選択肢を維持する。
2. **検索をコンパクトに**。会社名・コードの検索欄と今の状況を常時表示。並び順は検索枠から一覧直上へ移動。期間・会社説明の詳細条件は既存の折りたたみを使い、適用中の条件は折りたたみ外にも表示する。条件解除は条件がある時だけ目立たせる。検索URL・戻る操作・個人条件の扱いは維持。
3. **媒体を選択ボタンへ**。Mergermarket、選択、Bloomberg等を件数付きの小さなボタン風チェックボックスにする。選択時は背景色とチェック印で区別し、複数選択・キーボード操作を維持。0件は淡色で区別し、選択済み条件を勝手に消さない。報道なしの排他ルールは維持。
4. **一覧直上を整理**。左に結果件数と最終確認日、右に並び順。確認日の意味と並び順の詳しい説明は説明ボタン等から読めるようにし、長い説明を常時何行も並べない。確認日自体は1か所に常時表示する。
5. **行の操作感を統一**。今の3列を維持し、社名・媒体・状況の視覚的な区別と余白を整える。ホバーとキーボードフォーカスを明確にし、株探は詳細ページと同系統の小さなボタンへ。否定・未確認等の重要な状況補足は省略しない。
6. **スマートフォンのカードを短く**。社名と状況タグを上段に配置し、その下に媒体・噂の概要と状況補足をまとめる。各カードで繰り返す大きな項目名を減らす。本文や重要な但し書きを隠さず、縦の余白と重複表示を減らす。

上部の紹介文も短くまとめ、銘柄一覧が早く見えることを優先する。フォントは変えず、詳細ページと同じネイビー・白・薄いグレーの配色、丸み、ボタンの形を使う。大きな装飾画像や新たな集計カードは今回の主目的に含めない。

受入確認: PC/390px/320px、媒体複数選択、状況と段階の併用、0件・解除、URL復元、行クリック、外部リンク、お気に入り・メモ導線、スクリーンリーダー用ラベル。原則としてDB・認証・ドメイン変更は不要。
