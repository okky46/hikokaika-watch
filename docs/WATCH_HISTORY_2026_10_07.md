# 観察履歴と簡易試算

## 今回の判断

2026-10-07の追加指示：非公開化を疑うきっかけ、その後の値動き・情報の変化、最終結果の継続確認に集中する。過去TOBの詳細財務データベースと価格推定機能の拡充は主要対象から外す。既存データ・管理機能を保全し、過去TOBの詳細画面とPER・PBRの試算・比較は掲載を終了する。市場プレミアム・EV/EBITDA・実質NAVによる「価格の試算」だけを補助機能として残す。

主役を継続監視に置く。観察した事実、見立て、出来事の時期、記録した日時を分け、複数の起点・再燃・後日の説明を同じ案件で結ぶ。変化なし、別の材料で説明できた例、追跡終了も残せる。過去TOBの網羅的な財務補完・欠損解消は公開条件にせず、これまでの資料は保全する。

本番とAfter DealのTOB画面をブラウザーで確認した。要点から根拠へ進む構成を参考にしたが、外部データの転載や同規模のデータベース構築は行わない。ニュース収集Action・Discord通知の停止は維持する。

## 閲覧と運営

- 詳細の「気になった起点から、その後まで」で、観察と報道・開示を同じ経過へまとめる。確認日と確認結果の記録を別に示す。観察同士と既存の報道・開示を選択して関連付ける。
- 「ここまで確認済みにする」で読んだ内容をブラウザーに記録する。次回は追加・訂正・取り下げの件数と、残っている更新箇所へのリンクを表示する。古い出来事への追記も検出し、再ビルドだけでは更新にしない。
- トップは検索・絞り込み付きの追跡銘柄一覧に戻す。再訪先はマイページへまとめ、自分が監視する銘柄の理由・次の確認日・更新箇所と、記録・アカウントの管理を置く。確認状態はこのブラウザーの最大300案件で、端末同期・通知は行わない。取り下げられた記録は件数に含めるが、削除前の本文は保存しない。最新の画面と操作検証は [再構成の記録](WATCH_WORKSPACE_2026_10_07.md) を参照。
- 管理画面の既存の下書き保存→プレビュー／差分→公開承認→公開処理を使う。観察を追加し、見出し・事実・時期を入力する。価格や出来高、解釈、出典URLは任意。価格を使う場合は基準日と出典名が必要。
- AIで整理した配列も取り込める。IDなしは新規、同じIDは指定項目を更新し、配列にない既存記録は残す。取り込みは入力欄までで、保存・公開承認を自動では行わない。1案件200件まで。
- 新規の記録日時はDB保存時に付ける。再編集で記録日時を変更できない。古い出来事を今日整理した場合も、当時の記録に見せない。過去の解釈全文の版管理は今回追加していない。

取り込み例（UIがID・記録日時・省略項目を補う）：

```json
[
  {
    "kind": "origin",
    "title": "出来高の増加に着目",
    "occurred_on": "2026-10-07",
    "facts": "ここに確認した値動きと確認範囲を記す",
    "interpretation": "ここに仮説を記す",
    "observer": "運営者・AIによる整理"
  }
]
```

日が分からなければ `occurred_on` を空欄にし、`date_note` に「2026年6月（日は未確認）」などを書く。`kind` は `origin / observation / check / retrospective`、`outcome` は `open / no_change / explained / closed / confirmed`。関連する観察は `related_id`、既存出来事は `event_id` にIDを指定するか、入力欄で選ぶ。

## 価格の試算

| 方法 | 入力と計算 | 使える登録値・制約 |
| --- | --- | --- |
| 市場プレミアム | 基準株価×（1＋プレミアム） | 複数の観察時点や報道前終値を選択。30%は試すための仮定で、統計値ではない。自由入力も可。 |
| EV/EBITDA | （EBITDA×倍率−有利子負債＋現金等−EV加算調整）÷株式数 | 既存の会社予想・実績を明示操作で反映。残高の日付・範囲が不一致なら反映しない。金融業は不向きと案内。EBITDAが0以下なら計算しない。 |
| 実質NAV | （株主帰属純資産＋税引後の評価調整）÷株式数 | 同じ時点・範囲の実績BPSと株数から純資産を概算可能。時価未調査と調査済みの調整、自分の仮定を区別。負債は再控除しない。 |

EVとNAVは百万円・百万株で入力し、円／株を返す。方式を切り替えても入力を保持する。全方式は手入力だけでも使え、共通の財務データは書き換えない。三方式の平均・成立確率は出さない。株価の自動収集や資産時価の全面調査は追加しない。三方式で使う登録値と出典だけを折りたたみに残し、EPS・旧PER/PBR試算・同業TOB統計は公開HTMLへ含めない。

## 掲載を終了する画面

旧TOB一覧はナビゲーションとサイトマップから外す。既存URL `/tob-comparables/` はnoindexの掲載終了案内として残す。旧ページの実装は `ArchivedTobComparables.astro` に保全し、公開ページから呼ばない。銘柄詳細・企業ページから旧試算・過去TOB比較を外し、既存の企業URLと `#valuation` の移動先は維持する。一覧の空の株価・倍率列と切替を撤去する。登録データ・管理編集・取込・既存SQLは変更しない。

## DBと反映

SQL `0020_watch_observations.sql` は既存 `tracking_editions` のJSONへ任意の観察配列を追加する。既存の公開承認・revision競合検査・管理者権限を使い、記録日時をDBで固定する。新規テーブル、権限拡大、メモRLS変更、既存SQLの書換えはない。

開始時にGitHub main `5017451`、未マージPR0、Cloudflare本番 `e245d5a`（deployment `cf9d5170-6605-4732-8865-9068376c2e1c`）、Supabase適用履歴17件・最新0019を読み取り確認した。0020は本番へ未適用。反映時は通常のmain公開フローが0020を先に適用する。手貼りは不要。承認済みデータのサイト反映には既存どおり再ビルドが必要。
